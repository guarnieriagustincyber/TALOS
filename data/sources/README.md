# 📚 Directorio de Fuentes y Materiales por Cuaderno TALOS

Esta carpeta organiza los materiales de estudio de forma aislada para evitar contaminación entre materias y cuadernos.

## Estructura de Carpetas:
- `general/`           -> Libros canónicos y bibliografía transversal (Joyanes, Clean Code, Stallings, Ramalho, etc.)
- `fase0-soc/`         -> Roadmap Fase 0 (Programación, Guía UTN, Pensamiento Algorítmico)
- `fadena-lenguajes/`  -> Lenguajes de Programación (FADENA 1° Año 2° Cuatrimestre: clases, punteros, árboles, estructuras de datos)
- `fadena-so2/`        -> Sistemas Operativos II (procesos, memoria, concurrencia, hilos, planificación)
- `fadena-std/`        -> Sistema de Tratamiento de Datos (matemática discreta, algoritmos, bases de datos)
- `fadena-teleco/`     -> Infraestructura de Telecomunicaciones (redes, Kurose, modelos TCP/IP, capas OSI)
- `fadena-sye/`        -> Sociedad y Estado

## Subcarpetas admitidas:
Dentro de cada materia podés armar cualquier subcarpeta de clases o unidades (por ejemplo: `clase_01/`, `unidad_2/`, `diapositivas/`, `trabajos_practicos/`).
El motor de TALOS escanea todas las subcarpetas de forma **recursiva**, asociando el contenido única y exclusivamente a ese cuaderno.
