# Herramientas de búsqueda disponibles
Para buscar texto o código con expresiones regulares de forma rápida en este proyecto, ejecuta comandos usando la herramienta local `tgrep` instalada en el sistema.
- Comando base: `tgrep <patrón> <ruta>`
- Si la salida contiene demasiados datos, asegúrate de que el servidor `context-mode` intercepte la respuesta para resumirla.
